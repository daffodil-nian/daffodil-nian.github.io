这篇文章用来集中介绍我正在推进的毕业设计，以及同栈相关的课设 / 大创项目。仓库都在 GitHub 上，欢迎 star / fork / 提 issue。

毕设主线：仿 Bilibili 全栈系统

一句话：内容社区向的全栈毕设——用户、专栏、互动、搜索等能力逐步落地。

端 仓库 说明
后端 bilibili-fullstack-implementation-backend Spring Boot 等，含用户、专栏、互动、Redis / ES 等
前端 bilibili-fullstack-implementation-frontend Vue 3 + TypeScript + Vite

目前进度（摘自后端 README，2026-08-30）

  • 登录 / 注册：基本完成
  • 修改用户信息：基本完成
  • 专栏发布：入库、标签关联、已发布同步 ES
  • 专栏详情：权限校验、作者 / 标签 / 是否已赞、Redis 点击量
  • 专栏互动：投币 / 收藏 / 转发（表 + 实体 + Mapper）；主表补充投币数、收藏数
  • 评论：一级 / 二级评论 VO 已定；业务方法推进中
  • 笔记：doc/06-Redis操作笔记.md（点击计数等）

项目仍在完善中，后续会持续把评论、搜索体验、部署说明补齐。

课设彩蛋：乙女向互动游戏

仓库：loveloveGame

灵感取材自韩漫《恶女只有死亡结局》一类设定，做可通关的 Web 乙女 AVG（多分支、存档读档、结局解锁；后台可维护剧情）。技术栈以 Spring Boot + Vue 为主。

个人技术学习 / 课设 Demo，非官方改编，与原作出版方无关联。

敬请期待——脚手架与主线剧情还在按计划推进（开工约 2026-08-31，交付目标 2026-12-21）。

大创：文星跨海

仓库：wenxingkuahai

大创相关源码仓库。文档与能力会继续用 AI 辅助完善，公开说明随后补充。

有问题或想交流实现细节，可以在对应仓库提 Issue，或在本站留言。
