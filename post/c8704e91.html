软件工程知识库介绍

发表于2026-08-30|更新于2026-08-30|项目介绍
|总字数:523|阅读时长:1分钟|浏览量:

「软件工程知识库」这一块，我主要挂两类公开笔记：Java / Java Web 体系，以及 网络安全学习笔记。都是学习向整理，适合当目录导航用。

一、Java 学习笔记（推荐精读）

仓库：brianway/java-learning

定位：在线 Java 学习笔记，含博客讲解和源码实例（Maven 分模块），覆盖反射、代理、多线程、IO、集合、JVM、Java 8 等。

仓库结构

  • blogs：博客文档
  • java-base：基础巩固源码
  • java-multithread：多线程
  • java-container：容器
  • java-io：IO
  • java-jvm：JVM
  • java8：Java 8

博客主题一览（节选）

Java SE：反射、泛型、类加载器、代理 / AOP 小框架、多线程（传统 / 共享数据 / 并发库）、注解

Java Web：Tomcat、HTTP、Servlet、request / response、cookie / session、JSP

更适合在线阅读时，也可移步作者在 CSDN / oschina 的汇总文（见该仓库 README）。

协议：Apache 2.0。觉得有用请先给原仓库点 star，也是对作者整理工作的支持。

二、网络安全学习笔记

仓库：djytmdj/Network-security-study-notes

内容覆盖 WEB 安全、提权、APP 渗透、内网渗透与横向移动、红队思路、工具学习、靶场练习等，目录很全，适合当「安全笔记导航」。

常见板块包括：

  • WEB 安全基础（SQL 注入、XSS、文件上传、SSRF 等）
  • Windows / Linux 提权
  • 中间件漏洞（Apache / Nginx / Tomcat）
  • 内网渗透 & 横向移动
  • 应急响应、权限维持、安全加固
  • 渗透工具与靶场练习

重要声明（摘自原仓库）： 技术、思路与工具仅供学习，不得用于非法用途、盈利或未授权渗透测试。

和我自己仓库的分工

类型 仓库 用途
个人知识库 book 我自己的读书 / 计划 / 碎记
毕设代码 backend / frontend 可运行的全栈实现
公开教材型笔记 上文两个外链仓库 体系化扫盲与对照学习

之后如果我把「软件工程」相关笔记沉淀成自己的汇总仓，会再在本站更新入口。
